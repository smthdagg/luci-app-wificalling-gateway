# Wi-Fi Calling Gateway v1.4.0

- Full Simplified Chinese (zh-cn) LuCI translation catalog, compiled into a real `.lmo` language pack (`po/zh_Hans/` source, built by `scripts/po2lmo.py` at package build time) and packaged into the IPK for both `/usr/lib/lua/luci/i18n/` and `/usr/share/luci/i18n/`. Chinese interface uses Chinese descriptions and status; protocol names and technical fields (TLS, UDP, UUID, SNI, ALPN, Reality, WebSocket, ePDG, IMS, ASSURED, QUIC) stay English.
- Encrypted IMS activity log now records only handshake success/failure and sustained encrypted communication (ringing or calls lasting a few seconds); a new "Activity log" on/off toggle (default enabled) can stop recording entirely.
- Feed-ready structure: `PKG_MAINTAINER` / `LUCI_URL` declared, `po/zh_Hans/` + `po/templates/`, and `build-ipk.sh` aliases `zh_Hans` -> `zh-cn` mirroring `luci.mk`'s `LUCI_LC_ALIAS`.
- Verified ImmortalWrt 24.10 and 25.12 compatibility (identical ucode dispatcher i18n path, `LUCI_LC_ALIAS`, and `sing-box`/`firewall4`/`kmod-nft-tproxy` dependencies).
- Install package release `1.4.0-1`. Distribution options: Releases IPK, self-hosted opkg feed, and ImmortalWrt official feed (see README and `docs/zh-CN/SUBMITTING.md`).
